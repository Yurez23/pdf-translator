## Публичная граница пакета

Из `pdf_translator` экспортируются ровно восемь имён:

```python
from pdf_translator import (
    Block,
    ConversionError,
    ConversionResult,
    ConversionWarning,
    HyphenationIssue,
    HyphenResolver,
    SourceRegion,
    convert_pdf,
)
```

Рабочий API синхронный, не пишет выходные файлы и не обращается к сети. Вопросы
терминала не являются частью ядра: их добавляет CLI через callback. Промежуточные
типы и служебные функции доступны в исходных модулях, но не входят в эту границу;
формат JSON, сериализация модели и плагинный API не определены.

## `convert_pdf`

```python
def convert_pdf(
    input_path: str | Path,
    *,
    pages: str | Sequence[int] | None = None,
    hyphen_resolver: HyphenResolver | None = None,
) -> ConversionResult:
    ...
```

`Path` — `pathlib.Path`, `Sequence` — `collections.abc.Sequence`.

| Параметр | Контракт |
| --- | --- |
| `input_path` | Существующий файл. Относительный путь разрешается от текущего рабочего каталога. Шифрованные PDF отклоняются; параметра пароля нет. |
| `pages` | `None` — всё; строка вроде `"1,3-5"`; последовательность целых физических номеров, например `[5, 1, 3]`. Повторы удаляются, порядок сортируется. Пустой выбор, `bool`, дробные и выходящие за диапазон номера недопустимы. |
| `hyphen_resolver` | `None` — сохранять неоднозначный дефис с предупреждением. Функция — принимать решение по каждому неоднозначному случаю. |

Ключевые ограничения выбора страниц: весь PDF читается для структуры заголовков
и колонтитулов; невыбранные страницы не экспортируются, не задают вопросов и не
производят предупреждений. Ошибка чтения невыбранной страницы всё равно может
прервать вызов. Словарь переносов зависит только от выбранных страниц; через
пропуски страниц абзацы не соединяются.

Пример без файловой записи:

```python
from pathlib import Path
from pdf_translator import ConversionError, convert_pdf

try:
    result = convert_pdf(Path("book.pdf"), pages="10-25")
except ConversionError as error:
    print(f"Конвертация не выполнена: {error}")
else:
    print(result.markdown)
    for warning in result.warnings:
        print(warning.code, warning.pages, warning.message)
```

Для безопасной записи пары файлов используйте CLI. Если вызывающая программа
пишет `result.markdown` / `result.text` сама, защита от перезаписи, UTF-8, имена
файлов и обработка ошибок записи находятся на её стороне.

## `ConversionResult`

| Поле | Тип | Содержимое |
| --- | --- | --- |
| `markdown` | `str` | Готовый Markdown. |
| `text` | `str` | Готовый TXT без Markdown-разметки. |
| `warnings` | `tuple[ConversionWarning, ...]` | Предупреждения выбранных страниц, без точных дублей. |
| `blocks` | `tuple[Block, ...]` | Упорядоченные основные блоки, включая контейнеры вставок. |

`ConversionResult` — frozen dataclass, но это не глубокая неизменяемость:
содержащиеся `Block`, списки строк и дочерних блоков изменяемы. Если изменить
`result.blocks`, уже готовые строки `markdown` и `text` **не пересчитаются**.
Не следует изменять результат, если он используется как проверяемый снимок.

## `SourceRegion` и координаты

Frozen dataclass с обязательными полями:

| Поле | Тип | Значение |
| --- | --- | --- |
| `page` | `int` | Физический номер страницы с 1. |
| `bbox` | `tuple[float, float, float, float]` | `(x0, top, x1, bottom)` от левого верхнего угла, в PDF-пунктах. |

Это координаты PDF, не пиксели растрового превью. Для проверки на изображении
нужно учитывать масштаб рендера. `Block.sources` — кортеж областей, а не одна
общая рамка: продолжение может иметь несколько областей даже на одной странице
при переходе между колонками. Для рамочной вставки родитель хранит область рамки,
а дети — собственные области текста.

## `Block`: поля

`Block` — изменяемый dataclass. Первые три поля обязательны; списки по умолчанию
создаются отдельно для каждого экземпляра.

| Поле | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `kind` | `BlockKind` | Обязательно | Тип блока из списка ниже. |
| `text` | `str` | Обязательно | Плоский текст; у обычной таблицы пуст, у рамочной вставки — агрегат текста детей. |
| `sources` | `tuple[SourceRegion, ...]` | Обязательно | Исходные области. |
| `level` | `int` | `0` | Для основного заголовка 1–6; у вспомогательных заголовков 0. |
| `rows` | `list[list[str]]` | `[]` | Ячейки обычной таблицы. |
| `lines` | `list[Line]` | `[]` | Внутренняя геометрия исходных строк для продолжений; скрыта в repr. |
| `body_size` | `float` | `10.0` | Основной размер исходной страницы; скрыт в repr. |
| `container_width` | `float` | `0.0` | Оценка ширины текстовой области для проверки полноты строки; скрыта в repr. |
| `role` | `str` | `""` | Дополнительная роль из таблицы ниже; скрыта в repr. |
| `container_left` | `float \| None` | `None` | Левый край области для проверки отступа; скрыт в repr. |
| `children` | `list[Block]` | `[]` | Вложенные заголовки/абзацы/списки рамочной вставки. |

`BlockKind` определён в `models.py` как `Literal` семи строк. Типы сами по себе
не выполняют полную runtime-валидацию произвольно созданного пользователем блока.

### Виды блоков и экспорт

| `kind` | Markdown | TXT |
| --- | --- | --- |
| `paragraph` | Экранированный абзац на одной строке. | Обычный абзац. |
| `heading` | `#`–`######`; вспомогательные роли выделяются `**жирным**`. | Текст заголовка без маркеров уровня. |
| `list_item` | Маркер/номер и текст; стандартные буллиты нормализуются, неявному пункту добавляется `-`. | Исходный текст блока, без искусственно добавленного маркера. |
| `table` | Первая строка как шапка, строка `---`, затем строки данных; `\|` внутри ячеек. | Столбцы через табуляцию, строки через LF. |
| `aside` с детьми | Одна цитатная вставка: `> ` перед строками, `>` между внутренними абзацами. | Дочерние блоки с пустыми строками между ними. |
| `aside` без детей | Отдельная цитата `> текст`. | Обычный отдельный текстовый блок. |
| `footnote` | Отдельная цитата; без автоматической ссылки `[^n]`. | Отдельный текстовый блок. |
| `raw` | Отдельная цитата с сохранённым текстом. | Отдельный текстовый блок. |

Между основными блоками — пустая строка, в конце непустого документа — LF.
В MD экранируются специальные символы и потенциальные случайные маркеры в начале
обычной прозы. Числовые/буквенные обозначения пунктов сохраняются, но не каждый
такой маркер обязательно отобразится как нативный список в любом Markdown-рендерере.
TXT намеренно не кодирует иерархию заголовков или границы цитаты дополнительными
символами. Исходное жирное/курсивное оформление внутри обычного абзаца не переносится.

### Дополнительные роли

| `role` | Где используется | Смысл |
| --- | --- | --- |
| `""` | Обычные блоки | Нет специальной роли. |
| `table_title` | `heading`, `level=0` | Название таблицы вне основного оглавления. |
| `title_label` | `heading`, `level=0` | Короткая метка над более крупным названием. |
| `aside_title` | Дочерний `heading`, `level=0` | Заголовок внутри рамочной вставки. |
| `complex_table` | `raw` | Текстовый fallback сложной таблицы. |
| `rotated` | `raw` | Сохранённый неподдержанный повёрнутый текст. |

### Как обходить рамочные вставки без дублирования

`aside.text` содержит текст детей в плоском виде для поиска и совместимости.
Для структурированного чтения нужно обходить **либо детей, либо text**, но не оба.
Один контейнер с заголовком и двумя абзацами — не три независимые сноски.

```python
from collections.abc import Iterable, Iterator
from pdf_translator import Block

def leaf_blocks(blocks: Iterable[Block]) -> Iterator[Block]:
    for block in blocks:
        if block.kind == "aside" and block.children:
            yield from leaf_blocks(block.children)
        else:
            yield block

# result получен через convert_pdf(...).
# Таблицы нужно читать через rows, а не через пустой text.
```

## Предупреждения и ошибки

`ConversionWarning` — frozen dataclass:

| Поле | Тип | Значение |
| --- | --- | --- |
| `code` | `str` | Машинный код категории. |
| `message` | `str` | Человекочитаемое сообщение. |
| `pages` | `tuple[int, ...]` | Затронутые физические номера страниц. |

Текущие коды: `empty_page`, `unmapped_glyph`, `table_detection`,
`ambiguous_hyphen`, `complex_table`, `rotated_text`, `heading_depth`.
Разбирать лучше `code`, не русский текст сообщения. Одинаковые тройки
`(code, message, pages)` подавляются, поэтому число предупреждений не всегда
равно числу вхождений слова. [Справочник диагностики](troubleshooting.md)
объясняет последствия каждой категории.

`ConversionError` наследуется от `ValueError` и обозначает ожидаемую ошибку входа
или конвертации: отсутствующий/повреждённый/зашифрованный файл, неверные страницы,
отсутствие текста в выбранном диапазоне или пустой результат после очистки.
Шифрование отклоняется даже у PDF, открывающегося без запроса непустого пароля.
Не все ошибки приложения оборачиваются в `ConversionError`: в частности,
исключение пользовательского обработчика переносов передаётся вызывающему коду.

## Обработчик переносов

```python
type HyphenResolver = Callable[[HyphenationIssue], bool]
```

`HyphenationIssue` — frozen dataclass с обязательными полями:

| Поле | Тип | Пример/смысл |
| --- | --- | --- |
| `page` | `int` | Страница решаемой границы; при переходе страниц — страница продолжения. |
| `hyphenated` | `str` | `"fort-ress"` — вариант с дефисом. |
| `joined` | `str` | `"fortress"` — слитный вариант. |
| `context` | `str` | До 110 символов слева, LF, до 110 символов справа; это контекст вопроса, не готовый абзац. |

Возвращаемое значение строго `True` (слить) или `False` (сохранить дефис).
Например, `1`, `"join"` или `None` приводят к `TypeError`, а не преобразуются
по истинности. Обработчик вызывается только при нехватке подтверждений в словаре;
он не перехватывает все обычные дефисы. Это относится и к таблицам, и к вставкам.

```python
from pdf_translator import HyphenationIssue, convert_pdf

decisions: list[tuple[int, str, bool]] = []

def keep_and_record(issue: HyphenationIssue) -> bool:
    decisions.append((issue.page, issue.hyphenated, False))
    return False

result = convert_pdf("book.pdf", hyphen_resolver=keep_and_record)
```

С callback неоднозначность считается разрешённой: `ambiguous_hyphen` для неё
не добавляется. При `hyphen_resolver=None` дефис сохраняется с предупреждением.
Историю решений программа сама не сохраняет; пример выше хранит её только в
памяти вызывающего кода. Callback может иметь собственные побочные эффекты —
гарантия отсутствия файловой записи относится к ядру, а не к чужой функции.

## Внутренние модели для чтения исходного кода

Эти типы не экспортируются из корня пакета. Они помогают диагностике и тестам,
но не являются отдельным обещанным внешним контрактом.

| Тип | Поля и вычисляемые свойства |
| --- | --- |
| `BBox` в `models` | Псевдоним кортежа четырёх `float`. |
| `Word` в `models` | Обязательные `text`, `bbox`, `size`; `font=""`, `upright=True`, `angle=0.0`, `color=None`. Цвет — кортеж каналов, а не обязательный RGB. |
| `Line` в `models` | Обязательные `words`, `bbox`, `size`; свойство `text` соединяет слова пробелами, `bold_start` проверяет шрифт первого слова. |
| `TableData` в `layout` | `bbox`, `rows` (`list[list[str \| None]]`); `None` важен для распознавания сложной структуры. |
| `PageData` в `layout` | Обязательные `number`, `width`, `height`, `words`, `body_size`; пустые списки по умолчанию: `tables`, `frames`, `separators`, `dropcaps`, `images`. Рамки/буквицы/изображения — BBox, разделители — вертикальные координаты. |
| `HeadingStyle` в `headings` | Frozen dataclass: обязательные `size`, `font`, `color`; нужен для сравнения оформления и назначения уровней. |

Служебный `export.render(blocks)` возвращает пару строк, но не является публичной
функцией пакета для редактирования результата. Если в будущем потребуется
поддерживаемый API повторного экспорта, его контракт нужно определить отдельно.
