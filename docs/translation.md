# Перевод через Gemini

[Все разделы](README.md) · [Карта модулей](architecture.md) · [Локальная конвертация](usage.md)

## Границы и готовность

Gemini — основной провайдер первой интеграции перевода. Это **отдельный,
необязательный** этап: команда конвертации PDF по-прежнему работает локально.
Перевод принимает готовый UTF-8 `.md` или `.txt`, а не PDF. Рекомендуется Markdown:
в нём есть уровни заголовков, списки, таблицы и рамочные вставки, которых нет в TXT.

Без `--send` команда строит только локальный план: не читает ключ, не вызывает API,
не создаёт SQLite, журнал и выходные файлы. С `--send` текст, соседний контекст и глоссарий
передаются Google. Помимо офлайн-проверок логики и SDK, 19 октября 2026 года
выполнен отдельно разрешённый живой перевод всего `output/example.md`: три
пакета, 250 сегментов, модель `gemini-3.8-flash`, тайм-аут 300 секунд. Получены
оба формата; при проверке полноты пропусков и перестановок относительно исходного
Markdown не обнаружено. Это не сравнение разных моделей/размеров и не полная
оценка качества формулировок; доступность и остаток квот могут меняться.
Подробности и границы проверки — в [контроле качества](quality.md#живая-проверка-синхронного-перевода).

Ядро перевода не зависит от Gemini: конкретный адаптер выбирает CLI, а Python API
требует передать его явно. Другой переводчик подключается через общий порт без
изменений разбора, журнала, проверок или экспорта; подробнее — ниже в разделе DIP.
Других готовых сетевых адаптеров пока нет.

Нарезка по подразделам с жёстким капом **16 000 символов** реализована; запросы
пока последовательные. До пяти конкурентных запросов остаются в [TODO](../TODO.md).
Обоснование и пределы теоретических выводов — в [ресерче](research/translation-chunk-size.md).

## Подготовка аккаунта и окружения

1. Войти в [Google AI Studio](https://aistudio.google.com/) и создать отдельный
   проект. Для бесплатного использования оставить его на Free Tier, без
   подключения платного биллинга.
2. Создать API-ключ и сохранить его в пользовательской переменной окружения
   `GEMINI_API_KEY`. Запускать программу из нового процесса, который получил эту
   переменную. Не записывать ключ в код, журнал, аргументы CLI, чат или Git.
3. В AI Studio проверить Free Tier проекта. По умолчанию используется `--model auto`:
   свежий каталог и fallback по ответам сервера. Явный ID включает ручной режим.
4. Установить extra для перевода в окружение проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[translation]'
```

Extra включает `google-genai>=2.31,<3`, `markdown-it-py>=3,<5` и `tzdata>=2025.2`
(часовые пояса для сброса суточных квот с учётом DST). Рабочая зависимость
локального конвертера остаётся прежней. Extra `dev` включает также эти библиотеки,
чтобы тесты перевода и SDK выполнялись при полной проверке.

Официальные инструкции: [ключ](https://ai.google.dev/gemini-api/docs/api-key),
[биллинг](https://ai.google.dev/gemini-api/docs/billing),
[модели и цены](https://ai.google.dev/gemini-api/docs/pricing),
[квоты](https://ai.google.dev/gemini-api/docs/rate-limits).
Условия провайдера могут меняться. Наша программа **не умеет проверить тариф
проекта** и не гарантирует нулевой счёт при использовании ключа платного проекта.
Она может переключать модели только в режиме auto, но не переключает аккаунты,
не включает биллинг и не обходит ограничения проекта.

Бесплатный сервис может использовать запросы и ответы для улучшения продуктов
Google; перед отправкой оцените права на передачу материала и отсутствие
конфиденциальной информации. См. [условия Gemini](https://ai.google.dev/gemini-api/docs/terms).
SDK получает только `GEMINI_API_KEY`: посторонний `GOOGLE_API_KEY` не подставляется
вместо него. Используется Gemini Developer API, не Vertex AI.

## Первый запуск: только локальный план

Все команды ниже выполняются из корня репозитория. `python` означает Python
окружения с установленным extra; в PowerShell можно использовать
`.\.venv\Scripts\python.exe`. Установленный console script — `pdf-translate`.

```sh
python -m pdf_translator.translation output/example.md --limit-units 5
```

Команда покажет число элементов, сегментов и начальных пакетов, режим модели и
отпечаток снимка. Это не точное число будущих API-вызовов: ограничения модели и
подсчёт токенов становятся известны только при разрешённом сетевом запуске.
В auto конкретный каталог тоже получается только после `--send`.

`--limit-units` выбирает начальную пробу: включает целые верхнеуровневые блоки,
пока в них не окажется не менее N текстовых элементов. Таблица, список или рамка
не разрезаются пополам ради точного числа. Поэтому элементов может быть больше N.
Проба имеет свой fingerprint; её нельзя продолжить как полный документ через
тот же журнал. Для целой главы используйте отдельный каталог без `--limit-units`.

## Разрешённая отправка и возобновление

Следующая команда **отправит содержимое пробы Google**. Выполнять её нужно только
после подготовки ключа, проверки Free Tier и решения о передаче текста:

```sh
python -m pdf_translator.translation output/example.md --limit-units 5 --output-dir output/translations/sample --send
```

После остановки по бюджету или ошибке с сохранённым журналом:

```sh
python -m pdf_translator.translation output/example.md --limit-units 5 --output-dir output/translations/sample --send --resume
```

Сохраняйте параметры исходника, модели, языков, глоссария, пробы, размеров пакета,
контекста и ответа. Скорость, число разрешённых вызовов, повторы и тайм-аут при
возобновлении можно менять: они не меняют переводческий контракт. `--overwrite`
разрешает заменить итоговые файлы, но **не** сбрасывает несовместимый журнал.
Для нового перевода используйте новый каталог.

Если весь перевод уже сохранён в совместимом журнале, `--resume --overwrite`
пересоберёт MD/TXT без API и без ключа. Сохраняется требование явного `--send` /
`allow_network=True` как разрешения операции, хотя в этом частном случае вызовов нет.

## Автовыбор, fallback и SQLite

`--model auto` — режим CLI по умолчанию. Каталог получается через официальный
`models.list` один раз за запуск с несохранёнными сегментами, включая все страницы.
Каждый HTTP-вызов каталога учитывается общим защитным бюджетом. Во время полного
повторного экспорта уже готового журнала каталог, SDK и SQLite не нужны.

В каталог кандидатов входят модели семейства `gemini-<поколение>-pro`, `-flash`
и `-flash-lite` с поддержкой `generateContent` и положительными токенными пределами.
Распознаются стабильные, числовые ревизии, `preview`/`exp` с необязательной датой.
Live, TTS, image/Nano Banana, embeddings, robotics, Gemma, `latest` и неизвестные
семейства не включаются. Это правила распознавания класса, не список сегодняшних
ID. Новый номер поколения подхватывается автоматически; неизвестный новый класс
сначала требует явной поддержки, а не догадки по названию. `models.list` не
гарантирует бесплатность или поддержку JSON-schema: ошибка параметров не скрывается
слепым перебором. Явный `--model gemini-...` полностью отключает auto/fallback.

Строгий порядок: числовое поколение по убыванию (например, 3.10 выше 3.8), затем
Pro → Flash → Flash Lite внутри поколения, стабильная выше preview/exp,
числовая ревизия/дата и полный ID как однозначное разрешение равенства.
Так, новая Flash идёт раньше старой Pro. Это согласованная простая политика,
а не измеренный рейтинг качества перевода.

Ограничения сохраняются в **`model-availability.sqlite3` в корне этого checkout**.
В установленном wheel без корня исходников используется текущий рабочий каталог;
`--availability-db` позволяет задать путь явно. SQLite входит в стандартную
библиотеку Python, отдельный сервер/пакет не нужен. База и её служебные файлы
игнорируются Git. Она не включается в HTML и не содержит текстов, ключей, сырых
ответов ошибок или счётчика предполагаемого остатка квоты.

Таблицы схемы `user_version=1`:

| Таблица | Содержимое |
| --- | --- |
| `cooldowns` | namespace, модель (`*` для общего ограничения), причина, время наблюдения, `retry_at`, основание срока. Только отрицательные результаты с конечным сроком. |
| `aliases` | Наблюдаемые соответствия запрошенного ID и фактического ID ответа/ошибки. Псевдонимы не считаются заведомо независимыми квотами. |
| `leases` | Короткая аренда попытки: namespace, модель, случайный owner, срок. Снижает одновременные проверки несколькими процессами; не является гарантией квоты или глобальным RPM-ограничителем. |

Если задан `--project-id` или `GEMINI_PROJECT_ID`, namespace — SHA-256 ID проекта:
разные ключи этого проекта делят кэш. **Без настройки автоматически используется
SHA-256 ключа с отдельным префиксом**, не сам ключ; одинаковый ключ делит кэш между
запусками/книгами, другой ключ или смена ключа — другой namespace. Надёжно узнать
ID проекта из одного Gemini API-ключа программа не умеет. Для разных ключей одного
проекта задайте одинаковый project-id. Ни исходный ключ, ни project-id не пишутся в БД.

При каждом пакете модели проверяются в порядке приоритета; ещё действующие
ограничения пропускаются локально, без генерации/подсчёта токенов у этих моделей.
После истечения срока лучшая модель снова становится кандидатом. Успех снимает
старую отметку, но не стирает более новое ограничение другого процесса.

| Ответ/ситуация | Поведение auto |
| --- | --- |
| Модельная минутная квота | Сразу fallback; повтор не ранее задержки сервера и локальной осторожной минуты. |
| Модельная суточная квота | Fallback до RetryInfo/Retry-After либо ближайшей полуночи America/Los_Angeles + 5 секунд. Без tzdata — консервативные 25 часов, без угадывания DST. |
| Подтверждённая нулевая квота | Fallback с временной отметкой 6 часов, если сервер не требует большей задержки. |
| Неясный `429` | Fallback с короткой оценкой 60 секунд, не суточный запрет; более долгая серверная задержка соблюдается. |
| Явная общая квота проекта | Общее ограничение `*`, сохранение прогресса и `paused`, без перебора остальных моделей. |
| `404` конкретной модели | Fallback с отметкой 1 час (либо большей серверной задержкой). |
| `400/401/403`, невалидный JSON, фильтр, обрезка | Ошибка без переключения; исправить причину, не маскировать её другой моделью. |
| Сеть/`5xx` | Обычные ограниченные повторы, затем ошибка без слепого fallback. |
| Все модели ограничены/арендованы | `paused`, код `3`, сохранённый журнал и ближайшая оценка повторной попытки. |
| Не подходит размер ответа | Кандидат пропускается только для этой задачи, без глобальной отметки. Если не подходит никто — ошибка. |

Сырые сведения SDK разбираются только в памяти. При известном фактическом ID
он записывается в журнал и учитывается кэшем; до первого наблюдения нельзя
гарантировать распознавание всех серверных псевдонимов. Смена модели может менять
стиль разных фрагментов; проверяйте итог, даже если все технические проверки прошли.

База обновляется транзакциями, без удержания SQLite-транзакции во время HTTP.
Повреждённая, чужая или неизвестная версия базы не перезаписывается: программа
останавливается с понятной ошибкой. `--reset-availability` очищает ограничения и
алиасы только текущего namespace перед разрешённой работой; `--ignore-availability-cache`
временно игнорирует ограничения, но записывает новые. Аренды других процессов
эти флаги не отменяют. Оба флага действуют только в auto и ничего не меняют без
`--send`; для уже полностью готового журнала подготовка адаптера не вызывается.

## Все параметры CLI

| Аргумент | По умолчанию | Назначение |
| --- | --- | --- |
| `input` | Обязателен | UTF-8 MD/TXT, максимум 20 МиБ. |
| `--model` | `auto` | Каталог + fallback; явный ID `gemini-...` включает ручной режим без fallback. Тариф определяется проектом, не наличием модели в каталоге. |
| `--availability-db` | `model-availability.sqlite3` в корне проекта | Общий локальный кэш ограничений auto. Каталог пути должен существовать; источник/выходы/глоссарий и ссылки запрещены. |
| `--project-id` | `GEMINI_PROJECT_ID`, иначе namespace ключа | Общий namespace разных ключей одного проекта, только auto. Не секрет. |
| `--reset-availability` | Выключен | Сбросить ограничения/алиасы текущего namespace в auto с `--send`, не переводы. |
| `--ignore-availability-cache` | Выключен | В auto временно не учитывать отрицательный кэш, но сохранять новые ограничения. |
| `--send` | Выключен | Разрешить API; без флага только план и никаких записей. |
| `--output-dir` | `output/translations` | Каталог двух результатов и журнала. |
| `--source-language` | `EN` | Исходный код языка. |
| `--target-language` | `RU` | Целевой код языка; используется и в имени файлов. |
| `--glossary` | Нет | UTF-8 JSON-объект строковых пар терминов. |
| `--limit-units` | Весь файл | Начальная проба с целыми контейнерами. |
| `--max-chunk-chars` | `16000` | Жёсткий кап нормализованного переводимого текста с пробелами и разделителями. Можно уменьшить до 256, превысить 16000 нельзя. Смысловые границы описаны ниже. |
| `--max-input-tokens` | `12000` | Локальный предел входа с резервом на схему. Ограничение модели тоже учитывается. |
| `--max-output-tokens` | `16384` | Максимальный бюджет ответа, включая thinking. Не должен превышать ограничение модели; обрезанный ответ не принимается. Это запас для увеличенных фрагментов, не гарантия достаточности. |
| `--context-chars` | `1000` | Максимум исходного контекста заголовков/соседних элементов, который не нужно переводить в ответе. |
| `--requests-per-minute` | `5` | Консервативный скользящий минутный предел **всех** вызовов, включая metadata и countTokens. |
| `--tokens-per-minute` | `30000` | Локальный резерв входа плюс максимального ответа; это не счётчик биллинга Google. |
| `--max-requests` | `10` | Общий бюджет всех API-вызовов: страницы каталога, metadata, countTokens, генерация, fallback и повторы. Не суточная квота провайдера. |
| `--max-retries` | `2` | Дополнительные попытки временного сбоя в рамках общего бюджета. |
| `--timeout-seconds` | `300` | Тайм-аут одной API-попытки, от 1 до 300 секунд. SDK также передаёт его как серверный срок выполнения. Повторы могут увеличить общее время запуска. |
| `--resume` | Выключен | Требует существующий совместимый журнал. |
| `--overwrite` | Выключен | Разрешить замену итогов, но не исходника и не ссылок. |
| `-h`, `--help` | — | Справка без отправки текста. |

Значения скорости по умолчанию — осторожная стартовая настройка, **не обещание
квоты аккаунта**. В начале сетевого запуска узнаются токенные ограничения выбранной
модели; каждый пакет проходит countTokens. Для схемы резервируется 512 токенов.
Если пакет велик, он делится на группы сегментов с приоритетом смысловых границ;
слишком большой одиночный сегмент или неделимая пара заголовок/текст останавливают
запуск с подсказкой уменьшить размер/контекст/глоссарий и создать новый план.
Нельзя установить размер ответа, который один уже превышает минутный резерв.

## Смысловые фрагменты и жёсткий кап

Сначала определяется окно не длиннее **16 000 символов**, затем его конец
отступает назад к последней доступной границе законченного подраздела. Короткие
подразделы можно объединять. Учитываются Markdown-заголовки всех уровней, в том
числе вложенные подразделы длинного раздела; имена/номера разделов не хардкодятся.
Заголовок внутри цитатной вставки не становится границей основного раздела.

Если в окне нет подходящей границы подраздела, выбирается конец целого абзаца,
затем конец предложения. Заголовок или цепочка родитель/подзаголовок сохраняются
вместе хотя бы с первым предложением текста. Целый абзац имеет приоритет над
нарезкой по предложениям. Независимого ограничения в 24 элемента больше нет.

Кап считается по нормализованному тексту элементов, фактически отправляемому на
перевод: пробелы и защищённые маркеры учитываются; между элементами учитываются
два символа перевода строки. Это не длина исходного Markdown со всеми URL/разметкой
и не длина HTTP/JSON. Инструкция, глоссарий, соседний контекст, ID и JSON-схема
проверяются отдельно в полном входном токенном бюджете. Кап **никогда не
превышается** ради завершения подраздела, абзаца или предложения.

Списки, таблицы и вставки, помещающиеся в кап, по возможности сохраняются целиком.
Слишком большой контейнер делится по пунктам, строкам таблицы, абзацам, затем
предложениям. Строка таблицы/пункт сохраняются целиком, если помещаются; иначе
допускаются ячейки/внутренние блоки. Если контейнер ровно помещается, но не вместе
со своим заголовком, возможен внутренний разрез. Такое деление даёт предупреждение
с ID и видом контейнера; при экспорте его структура восстанавливается.

Разделитель предложений — консервативная эвристика для английского текста: защищает
распространённые сокращения, инициалы, аббревиатуры, десятичные числа и часть
кавычечных продолжений. Это не универсальный лингвистический анализатор. Слова,
маркеры и распознанные предложения не режутся по пробелу ради капа. Если отдельное
предложение/заголовок длиннее капа либо заголовок с первым предложением не помещаются
вместе, возникает понятная ошибка до отправки и создания журнала. Для TXT без
заголовков используются абзацы/предложения с прежним предупреждением об отсутствии
иерархии. Экспорт объединяет сегменты обратно без потери пробелов или новых абзацев.

Токенные ограничения выбранной модели остаются отдельным, более строгим барьером.
При `BatchTooLarge` пакет повторно делится по существующим ID и смысловым границам;
заголовок не отправляется один. Новый ID/план посреди возобновляемого перевода не
создаётся. Если безопасного деления нет, запуск останавливается, а не обрезает текст.
Ответный бюджет увеличен до 16384 токенов, но достаточность для любого фрагмента
и качество длинного перевода без живого сравнения не доказаны.

## Глоссарий

Формат файла, например `glossary.json` (значения определяет пользователь):

```json
{
  "purpose": "предназначение",
  "obstacle": "препятствие"
}
```

Максимум 500 пар, по 500 символов на термин, до 30000 символов JSON суммарно.
Пустые значения, переносы строк и повторяющиеся ключи не принимаются.
Глоссарий передаётся как данные, а не как возможность добавлять произвольные
инструкции. Соблюдение терминологии моделью всё равно нужно проверять вручную.

## Структура, промпт и проверки

Markdown разбирается `markdown-it-py` в дерево: заголовки, абзацы, цитатные вставки,
списки, таблицы. Текстовые элементы получают ID, длинные — дополнительные ID
сегментов. Форматирование, inline-код и ссылки защищены маркерами. Модель должна
вернуть JSON с точным набором ID; порядок итогового документа задаёт исходное
дерево, а не порядок ответа. Заголовки и ячейки переводятся, числовые/пустые ячейки
не требуют API-вызова. Пустые ячейки сохраняются.

Англоязычная инструкция требует полного перевода без пересказа, сокращений,
дописок, выполнения команд из книги и перевода контекста. Поиск, инструменты,
автоматические function calls и загрузка файлов не включаются. Абсолютной защиты
от ошибок/инъекций самой языковой модели промпт не гарантирует; ответ дополнительно
проверяется локально.

Невалидный JSON, пропущенные/лишние/повторённые ID, изменённые или переставленные
маркеры, пустой или подозрительно короткий/длинный ответ отклоняются целиком для
пакета. Ответ SDK принимается только при единственном кандидате и `STOP`;
`MAX_TOKENS` или safety-block не превращаются в «готовый перевод».
Изменение набора чисел и неизменившийся длинный текст дают предупреждения для
ручной сверки. Эти эвристики не доказывают смысловую полноту: длинный пересказ,
ошибка значения, неверный термин или пропущенное предложение могут их пройти.

Кодовые блоки сохраняются без перевода. HTML-блоки сохраняются в кодовых ограждениях,
а inline-HTML — как буквальный текст; изображения и alt-текст не переводятся.
Markdown-оформление может нормализоваться: маркеры буллитов, пробелы, ограждения
и выравнивание таблиц не обещают побайтового совпадения. Содержимое inline-кода и
адреса ссылок сохраняются. Это не универсальный редактор произвольного Markdown:
неподдержанные структуры вызывают ошибку, а не молчаливое удаление.

TXT сохраняет абзацы, явные маркеры и простые таблицы с табуляцией. Уровни заголовков
и границы рамок в TXT отсутствуют; программа их не угадывает и предупреждает.

## Файлы и надёжность

Для `example.md`, языка RU и каталога `output/translations/sample`:

```text
example.ru.md
example.ru.txt
example.ru.translation.json
```

Итоги появляются только после полного перевода выбранного диапазона. До этого
сохраняется JSON-журнал с переводами принятых пакетов, fingerprint/manifest,
счётчиком всех попыток и минутными резервами. Журнал содержит перевод книги:
обращайтесь с ним как с содержательным документом, не публикуйте автоматически.
Ключ, сырые ответы ошибок и URL запросов в него не записываются.

Fingerprint включает SHA-256 исходных байтов, модель/языки, семантические настройки,
глоссарий, имя и ревизию адаптера, версию общего контракта, политику фрагментации
и план сегментов **вместе с границами пакетов**.
Ревизия Gemini учитывает промпт, схему и настройки генерации. Переводы разных
провайдеров/ревизий не смешиваются. В auto fingerprint фиксирует режим и политику,
не сегодняшний состав каталога: возобновление получает свежий список, сохраняя
старые переводы. В журнале `segment_models` хранит фактическую модель каждого
принятого сегмента, `catalog` — последний каталог успешного пакета.
Формат журнала имеет версию `3`, контракт планирования — `3` (смысловые фрагменты).
Журнал со старым контрактом `2` несовместим даже при прежнем ручном капе 4000;
старые форматы журнала `1/2` тоже автоматически не мигрируют. Нужна новая папка,
а не удаление или перезапись прежнего прогресса. Несовместимый журнал отклоняется.
Одновременно писать один журнал нельзя: используется эксклюзивный `.lock`.
После аварийного завершения файл блокировки может остаться — перед ручным удалением
убедитесь, что другой процесс не работает. Журнал обновляется через временный файл
и замену. Минутная история учитывается при продолжении того же журнала; отдельные
каталоги/процессы не координируют общую квоту проекта.

SDK-повторы отключены; временные сетевые/серверные ошибки имеют ограниченные повторы
с задержкой; учитываются RetryInfo и заголовок Retry-After. В auto модельная квота
передаётся маршрутизатору без бесполезных повторов на той же модели.
В ручном режиме недневные 429 имеют ограниченные повторы.
Явно дневная квота и рекомендованная задержка больше 60 секунд
не повторяются автоматически. Если сервер не указал тип квоты, точно отличить
суточную от минутной нельзя: auto использует короткий cooldown, ручной режим
после ограниченных попыток завершится ошибкой.
Лимит вызовов считается **до** каждой попытки; исчерпание даёт `paused` и код `3`.

Гарантии «ровно один запрос навсегда» нет: тайм-аут или сбой после ответа сервера,
но до сохранения пакета, может привести к повтору при возобновлении. Уже сохранённые
и проверенные сегменты повторно не генерируются. Изменившаяся под тем же ID модель
на стороне провайдера тоже не контролируется нашей программой.

Файлы защищены от случайной замены и символических ссылок; исходник не перезаписывается.
С `--overwrite` пара результатов, как и у конвертера, **не общая транзакция**:
первый файл может замениться до сбоя второго. Журнал позволяет повторить экспорт.
Выбор разных настроек пробы, модели или словаря требует новой папки, а не очистки
существующего прогресса.

## Python API

Из `pdf_translator.translation` экспортируются:
`plan_translation`, `translate_file`, `TranslationOptions`, `TranslationPlan`,
`TranslationResult`, `TranslationError`, а также порты и их DTO:
`ProviderIdentity`, `TranslationProvider`, `TranslationRequest`, `TranslationItem`,
`RequestExecutor`, `BatchTooLarge`, `TranslationResponse`. `TranslationError` наследуется от `ValueError`;
локальные `OSError` и `KeyboardInterrupt` также могут выйти из файлового API.

```python
from pdf_translator.translation import TranslationOptions, plan_translation
from pdf_translator.translation.gemini import GeminiProvider

options = TranslationOptions(model="gemini-3.5-flash-lite")
provider = GeminiProvider()  # Без ключа, SDK и сети; только локальная identity.
plan = plan_translation("output/example.md", options, provider=provider.identity, limit_units=5)
print(len(plan.document.units), len(plan.segments), len(plan.batches))
```

`TranslationOptions` содержит поля одноимённых параметров CLI из таблицы выше,
кроме путей, `send`, `resume`, `overwrite`, `glossary`, `limit_units`, `project_id`
и флагов доступности. Они задаются при создании `GeminiAutoProvider`.
Это frozen dataclass с валидацией диапазонов. Общий `model` — ID модели/движка
любого провайдера (непустой, без пробелов/управляющих символов, до 200 символов).
Правило `gemini-...` / запрет `latest` проверяет только адаптер Gemini и его CLI,
не общее ядро. Токенные параметры применяет Gemini; адаптер без токенов может
их не использовать, но обязан соблюдать общий бюджет внешних вызовов.
`TranslationPlan` содержит
`document`, `segments`, `batches`, `manifest`, `fingerprint`, `glossary`.
Заморозка контейнера не делает вложенные словари/дерево глубоко неизменяемыми.
`TranslationOptions.max_chunk_chars` по умолчанию равен `16000`, допустимы `256–16000`;
`max_output_tokens` по умолчанию `16384`. Эти значения одинаковы в CLI и API.

Вызов с сетью и файловой записью:

```python
from pdf_translator.translation import translate_file
from contextlib import closing

# Только после разрешения отправить выбранный текст Google:
# with closing(provider):
#     result = translate_file(
#         "output/example.md", output_dir="output/translations/sample",
#         options=options, provider=provider, limit_units=5, allow_network=True,
#     )
```

Полная сигнатура: `translate_file(input_path, *, output_dir, options, provider,
allow_network=False, glossary=None, limit_units=None, resume=False, overwrite=False,
progress=None)`. Для локального плана используется отдельная функция
`plan_translation(input_path, options, *, provider, glossary=None, limit_units=None)`:
здесь `provider` — `ProviderIdentity`, а в `translate_file` — экземпляр адаптера.
Глоссарий в API — mapping строк, не путь. `progress` получает строку состояния;
исключения пользовательского callback не скрываются. Адаптер обязателен, никакого
неявного создания Gemini нет. Инъекция не отменяет `allow_network=True`, даже
для полностью локальной реализации порта. Ресурсами адаптера владеет вызывающий
код: CLI закрывает Gemini в `finally` через `closing`, ядро не требует `close()`.
При полном кэше или отсутствии переводимых сегментов не вызываются даже `prepare`
и `translate`; экземпляр Gemini можно создать и повторно экспортировать без ключа.

`TranslationResult`: `status` (`complete` / `paused`), `completed_segments`,
`total_segments`, `requests_made` (в этом запуске), `warnings` (кортеж строк),
`checkpoint`, `markdown_path`, `text_path` (абсолютные пути, у paused итоговые пути
равны `None`), `pause_reason` (строка для paused, иначе `None`). Auto при исчерпании
кандидатов/общей квоте возвращает paused; квота ручного адаптера остаётся исключением.

Автоматический адаптер создаётся из отдельного модуля, без импорта SDK/ключа/БД:

```python
from pdf_translator.translation import TranslationOptions, plan_translation
from pdf_translator.translation.routing import GeminiAutoProvider

options = TranslationOptions(model="auto")
provider = GeminiAutoProvider()  # SQLite по умолчанию в корне проекта.
plan = plan_translation("output/example.md", options, provider=provider.identity)
```

Его конструктор: `GeminiAutoProvider(*, database_path=None, project_id=None,
reset_cache=False, ignore_cache=False, progress=None, clock=time.time)`.
`clock` — точка подмены времени для тестов; `progress` получает безопасные сообщения
о выборе/пропуске/fallback. Запуск выполняется тем же `translate_file` с `closing`
и явным `allow_network=True`; один экземпляр адаптера не используется параллельно.

Внутренние модели в [translation/models.py](../pdf_translator/translation/models.py):
`ProtectedToken(marker, markdown, text)`, `TranslationUnit(id, text, kind, protected, context)`,
`DocumentNode(kind, unit_id, children, level, text, marker, start, rows)`,
`TranslationDocument(nodes, units, warnings)`,
`TranslationSegment(id, unit_id, text, separator)`, `ModelLimits(input_tokens, output_tokens)`.

## DIP: как заменить переводчик

Порты определены в [translation/ports.py](../pdf_translator/translation/ports.py).
`runner` и `planning` зависят от них, не от SDK. Адаптер Gemini также реализует
эти порты. Конкретный объект создаётся только в точке сборки приложения —
[translation/cli.py](../pdf_translator/translation/cli.py) — или вызывающим API кодом.
Добавлять LLM-методы в новый переводчик не нужно.

| Часть порта | Контракт |
| --- | --- |
| `ProviderIdentity(name, revision)` | Публичные ID без секретов: 1–128 символов из букв ASCII, цифр, точки, дефиса, подчёркивания; первый — буква/цифра. Менять revision при изменении переводческого поведения адаптера. |
| `TranslationItem(id, text, kind)` | ID сегмента, защищённый текст и роль: заголовок, абзац, ячейка и т. п. |
| `TranslationRequest(items, source_language, target_language, glossary, context)` | Данные задачи, без промпта или требований к JSON/HTTP. Контекст не включается в перевод. |
| `TranslationProvider.identity` | Локальная identity, доступная без ключа/SDK/сети. Участвует в fingerprint ещё до подготовки адаптера. |
| `prepare(options)` | Только локальная проверка настроек, зависимостей и ключей. Никаких сетевых запросов. |
| `translate(request, *, executor)` | Mapping `ID → перевод` либо `TranslationResponse` с точным набором ID и сохранёнными маркерами. JSON/REST/SDK скрыты внутри адаптера. Ядро повторно проверяет значения целиком до записи пакета. |
| `TranslationResponse(translations, model, catalog=())` | Нейтральный ответ с фактическим ID модели и необязательным снимком кандидатов. Для простого mapping в журнал записывается `options.model`. |
| `RequestExecutor.call(operation, *, tokens=0, label)` | Каждый внешний вызов, включая metadata, проходит через общий бюджет/повторы. Операция делает ровно одну попытку; label не содержит текст или секреты. Токенный резерв необязателен для нетокенного провайдера. |
| `BatchTooLarge` | Адаптер не может принять пакет: ядро делит его на меньшие группы. Если не помещается один сегмент, останавливается с понятной ошибкой. |

Пример полностью локального адаптера-заглушки — не настоящий переводчик:

```python
from pdf_translator.translation import ProviderIdentity, TranslationOptions, translate_file

class DemoProvider:
    identity = ProviderIdentity("demo", "v1")

    def prepare(self, options):
        pass  # Только локальная подготовка.

    def translate(self, request, *, executor):
        # Сетевой адаптер вместо этого вызывает executor.call(одна_попытка, ...).
        return {item.id: item.text for item in request.items}

# Только по явной команде на запуск/запись:
# result = translate_file("chapter.txt", output_dir="output/demo",
#     options=TranslationOptions(model="demo-engine"), provider=DemoProvider(),
#     allow_network=True)
```

Для реального нового провайдера достаточно написать адаптер и передать его в API.
Чтобы его выбирал CLI, меняется только точка сборки и относящиеся к провайдеру
подсказки/валидация CLI; `runner`, `planning`, парсер, хранилище и рендерер не меняются.
Флага `--provider` и автоматической загрузки плагинов пока нет. Наследоваться от
Gemini не требуется: `TranslationProvider` — структурный `Protocol`.

Промпт, JSON-schema и декодирование ответа Gemini находятся в
[gemini_format.py](../pdf_translator/translation/gemini_format.py); metadata,
countTokens, лимиты и generateContent — в самом адаптере. Любой адаптер обязан
санитизировать ошибки (`ProviderError` в `models.py`), не отправлять незаявленные
данные, отключить собственные повторы и не обходить `executor`. Это контракт
доверенного кода, не техническая песочница для сторонних плагинов.

## Диагностика и проверка качества

Коды CLI: `0` — план или полный экспорт, `1` — ошибка, `2` — неверные аргументы,
`3` — пауза по бюджету/доступности моделей с журналом, `130` — отмена.

- Нет ключа/SDK: подготовить окружение; сам ключ не печатать для диагностики.
- 401/403: проверить ключ, регион/проект. Не запускают слепой fallback.
- 404: ручной режим завершается ошибкой; auto временно пропускает конкретную модель.
- Нет кандидатов/все ограничены: смотреть прогресс и `pause_reason`; при известном
  изменении доступа использовать `--reset-availability` или `--ignore-availability-cache`.
- SQLite занята/повреждена: проверить путь и другие процессы; выбрать другую БД,
  не стирать автоматически чужой файл или журнал переводов.
- 429: проверить квоты, замедлить запросы или продолжить после восстановления.
- Несовместимый журнал: вернуть прежние настройки или использовать новую папку.
- Невалидный/обрезанный ответ: уменьшить пакет либо выбрать допустимый больший
  ответ. Если меняется семантическая настройка, нужен новый каталог.
- «Изменился набор чисел» / «текст не изменился»: сверить указанный ID с исходником;
  это предупреждение, не автоматическое исправление или доказательство ошибки.

Живая проба всей контрольной главы уже завершена, её полнота проверена отдельно.
Оценка терминологии и качества формулировок пользователем отложена. Новые живые
пробы требуют отдельного разрешения; успех mock-тестов их не заменяет.
Независимый PDF-аудитор автоматически не запускается и не становится переводческим
аудитором. Тесты без ключа и сети:

```sh
python -m unittest tests.test_translation tests.test_translation_ports tests.test_gemini tests.test_routing -v
python -m unittest tests.test_chunking -v
python -m unittest discover -v
```
