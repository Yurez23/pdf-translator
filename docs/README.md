# Документация проекта

PDF Translator — локальная Python-программа, которая превращает PDF с текстовым
слоем в связные Markdown и TXT. Перевод через Gemini — отдельный необязательный
этап с явным разрешением отправки текста. OCR и веб-интерфейс не входят в задачи
проекта. Основной целевой материал — англоязычные
книги с горизонтальным письмом слева направо и одной или двумя колонками.

Карта кодовой базы охватывает каждый исходный, тестовый, конфигурационный и
документационный файл проекта. Справочник API перечисляет все имена, экспортируемые
пакетом, поля моделей и роли блоков; диагностика — все текущие коды предупреждений.
Временные файлы, пользовательские PDF и результаты запусков описаны по назначению
каталогов: индивидуальный каталог каждого старого запуска не является частью API.

Источником поведения остаётся код, а настроек сборки и зависимостей —
[pyproject.toml](../pyproject.toml). Документацию нужно обновлять вместе с изменением
соответствующего контракта; порядок такой проверки приведён в разделе разработки.
Запись в документации о тесте или аудите не означает, что он был выполнен для
конкретного файла: это подтверждают результаты запуска и данные проверенного снимка.
