# PDF → связный текст для перевода

Локальный конвертер PDF в Markdown и TXT на Python 3.12+. Восстанавливает порядок
чтения в одной/двух колонках, собирает строки в абзацы, сохраняет заголовки, списки,
простые таблицы и отдельные боковые вставки. Файлы не отправляются в интернет.

OCR и веб-интерфейс не входят в цели проекта и не планируются. Программа работает
через командную строку с PDF, в которых уже есть текстовый слой.

## Установка

Из папки проекта в PowerShell, при установленном Python 3.12 или новее:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

На Linux/macOS используйте `python3.12 -m venv .venv`, затем
`.venv/bin/python -m pip install -e .`.

## Конвертация

```powershell
.\.venv\Scripts\python.exe -m pdf_translator example.pdf --output-dir output
.\.venv\Scripts\python.exe -m pdf_translator book.pdf --pages 10-25 --output-dir output
```

После установки также доступна команда `pdf-translator` из окружения.
Если зависимости уже установлены, из корня проекта можно запускать
`python -m pdf_translator ...` без установки самого пакета.

- Без `--pages` обрабатывается весь PDF. Поддерживаются диапазоны и отдельные
  страницы: `--pages 1,3-5`. Нумерация начинается с 1 и соответствует положению
  страницы в файле, а не номеру, напечатанному на странице. Результат всегда идёт
  в исходном порядке; через пропущенные страницы абзацы не склеиваются.
- Создаются `output/book.md` и `output/book.txt` в UTF-8. Абзацы занимают по одной
  строке и разделяются пустыми строками. В TXT столбцы таблиц разделены табуляцией.
- Существующие результаты сохраняются. Для их замены добавьте `--overwrite`.
  Исходный PDF не перезаписывается.
- При неоднозначном переносе CLI показывает страницу и окружающий текст, затем
  спрашивает: `1` — слить слово, `2` — сохранить дефис, `Q`/Esc — отменить конвертацию.
  В обычном терминале достаточно одного нажатия без Enter. Решение принимается
  отдельно для каждого случая и применяется сразу к обоим выходным форматам.
  До завершения всех ответов файлы результата не записываются.
- Для запуска без вопросов есть `--hyphens keep` (сохранять неоднозначные дефисы)
  и `--hyphens join` (убирать их). По умолчанию действует `--hyphens ask`.
  При перенаправлении stdin можно подавать ответы по одному на строку; окончание
  ввода до ответа завершает команду ошибкой, без молчаливого выбора за пользователя.
- Предупреждения с номерами страниц выводятся в stderr. Код завершения: `0` при
  успешном экспорте (в том числе с предупреждениями), `1` при ошибке файла или
  конвертации, `2` при неверных аргументах команды, `130` при отмене пользователем.

## Python API

```python
from pdf_translator import ConversionError, convert_pdf

try:
    result = convert_pdf("book.pdf", pages="10-25")
except ConversionError as error:
    print(error)
else:
    print(result.markdown)
    print(result.text)
    for warning in result.warnings:
        print(warning.code, warning.pages, warning.message)
    for block in result.blocks:
        print(block.kind, block.text, block.sources)
```

Функция не пишет файлы и не обращается к сети. `pages` также принимает список
целых номеров страниц. `ConversionResult` содержит оба формата, предупреждения
и упорядоченные блоки. `Block.sources` сохраняет номера страниц и прямоугольники
`(x0, top, x1, bottom)` в PDF-пунктах от левого верхнего угла; у абзаца, продолжающегося
на другой странице, несколько исходных областей. Для таблицы содержимое находится
в `Block.rows`; `Block.text` пуст. Python API позволяет вызывать конвертер из других
локальных программ и скриптов.

Python API по умолчанию не задаёт вопросов: неоднозначные дефисы сохраняются с
предупреждениями. При необходимости передайте `hyphen_resolver`: функцию, которая
получает `HyphenationIssue` с полями `page`, `hyphenated`, `joined`, `context` и
возвращает `True` для склейки или `False` для сохранения дефиса. Например:

```python
result = convert_pdf("book.pdf", hyphen_resolver=lambda issue: True)
```

Обработчик вызывается только для неоднозначных случаев. Заведомые переносы и
составные слова, подтверждённые остальным выбранным текстом, обрабатываются автоматически.

## Что восстанавливается и какие есть ограничения

- Повторяющиеся верхние/нижние колонтитулы и отдельные номера страниц удаляются
  по повторяемости и расположению у края. На коротких диапазонах повторяемость
  может быть недостаточной: в этом случае текст сохраняется.
- Слияние абзацев опирается на геометрию, отступы, шрифты и пунктуацию.
  Явные продолжения между колонками и соседними страницами соединяются.
- Лигатуры раскрываются, пробелы нормализуются, мягкие переносы удаляются.
  Обычный дефис на границе строк убирается, только если слитное слово встречается
  в выбранном тексте, а вариант с дефисом не встречается. Неоднозначный вариант
  в Python API сохраняется с предупреждением `ambiguous_hyphen`, а в CLI предлагается
  на выбор пользователю. Это правило намеренно осторожное.
- Простые таблицы распознаются по линиям и границам ячеек. Сложные таблицы
  с объединёнными ячейками сохраняются отдельным текстовым блоком с предупреждением.
  Таблицы без видимых границ могут остаться обычным текстом.
- Вставки в распознанных заполненных рамках и сноски выделяются в отдельные блоки.
  Вставки без рамок и нетипичные сноски могут распознаваться как обычные абзацы.
- Изображения не экспортируются; доступные текстовые подписи сохраняются.
  Короткие вертикальные имена художников мелким шрифтом на внешних полях за
  пределами основных колонок отфильтровываются по совокупности этих признаков.
  Произвольный повёрнутый текст не удаляется: полезные подписи внутри страницы,
  крупные надписи и фрагменты с числами сохраняются.
  OCR, перевод, вертикальное письмо и восстановление формул не поддерживаются.
  Поворотный текст сохраняется отдельно с предупреждением `rotated_text`;
  его порядок может потребовать ручной правки.
- Нужен PDF с текстовым слоем. Шифрованные и повреждённые файлы получают понятную
  ошибку. Пустая страница внутри текстового документа пропускается с предупреждением.

Первая версия рассчитана на англоязычные книги с горизонтальным письмом слева
направо. Это эвристический конвертер: сложная журнальная вёрстка, формулы,
трёхколоночные страницы и ошибки кодировки исходного PDF требуют ручной проверки.
Успешное завершение без предупреждений не гарантирует восстановления любой вёрстки.

## Проверка

Установите зависимости для генерации небольших контрольных PDF:

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m unittest discover -v
```

Тесты создают временные PDF и проверяют порядок колонок, целостность абзацев,
переносы, списки, таблицы, сноски, рамки, выбор страниц, ошибки входа и защиту
от перезаписи. Если в корне есть `example.pdf`, дополнительно проверяются начало
главы, списки и таблица на странице 7 этого локального примера. Сам пример
не включён в пакет; без него эти регрессионные проверки пропускаются.

Основные модули: `converter` извлекает данные и предоставляет публичный API,
`layout` восстанавливает структуру, `text` нормализует текст, `export` формирует
Markdown/TXT, `cli` отвечает за аргументы и запись результатов.
